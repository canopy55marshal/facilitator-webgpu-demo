## 促动师训练（零服务器）Browser-WebGPU Demo适合你的约束：**不买云服务器**、也**不本地部署后端**。做法是：- 只部署一个**纯静态网页**（GitHub Pages / Cloudflare Pages / Vercel 都免费）- 大模型推理在**用户浏览器本地**用 WebGPU 跑（无需你提供服务器算力）### 你将得到- 场景选择：会议促动 / 冲突调解 / 需求访谈 / 一对一教练- 你扮演促动师提问；浏览器里的模型扮演对话对象回答- 点击「完成」后一次性生成复盘（结果导向 + 关键点 + 3句改写 + 单一训练目标）- 导出对话 JSON（用于后续 SFT / DPO）---## 使用方式### 方式A：直接静态托管（推荐）把整个文件夹部署为静态站点即可（不需要 Node/Python 后端）。**GitHub Pages（最常见）**1. 新建一个 GitHub repo，把此文件夹内容上传到仓库根目录2. Settings → Pages → Deploy from branch（选择 main / root）3. 等待几分钟，打开 Pages 给你的 URL**Cloudflare Pages / Vercel**- 选择“静态站点”导入仓库即可，无需构建命令（Build command 留空）---## 重要限制（你需要提前知道）1. **首次打开会下载模型（几百MB～1GB）**：第一次慢，之后浏览器会缓存。2. 需要 **Chrome/Edge 支持 WebGPU**（你的目标用户是电脑端，匹配）。3. 模型越小越快，但“像真人”的上限也更低；等你愿意换商业API时，可以把同一套前端改成走云推理。
